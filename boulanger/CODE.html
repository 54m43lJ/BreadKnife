1. 文件树（规划）

src/
├── lib.rs           # 公开面出口：Service / ServiceHandle / 错误
├── registry.rs      # 登记簿记：在册 Item 表 / Host 表（内存）
├── service.rs       # 服务生命周期：名持有、导出、停止、让位

└── bin.rs           # 独立常驻形态（bin 目标，信号退出）

2. 类型与方法签名

/// 进程内组装侧唯一公开面：服务启动/停止形态，无回调、无数据面
pub struct Service;

impl Service {
    /// 申请持有 Watcher 名（allow-replacement）并导出协议面；阻塞至名字在位
    pub fn start() -> Result<ServiceHandle, WatcherError>;
}

pub struct ServiceHandle { /* 内部连接与登记簿记 */ }

impl ServiceHandle {
    /// 停止服务：释放名字、清理簿记；幂等；drop 自动调用
    pub fn stop(&self);
}

pub struct Registry {
    items: Vec<ItemEntry>,   // 在册 Item：唯一名 + 对象路径
    hosts: Vec<HostEntry>,   // 在册 Host：展示方标识
}

#[derive(Debug, thiserror::Error)]
pub enum WatcherError {
    #[error("session bus connect failed: {0}")]
    Bus(String),
    #[error("watcher name already owned elsewhere: {0}")]
    NameTaken(String),
    #[error("dbus call failed: {0}")]
    Protocol(String),
}

2.1 协议面（iface.rs，DBus 接口形态）

#[interface(name = "org.kde.StatusNotifierWatcher")]
impl WatcherIface {
    fn register_status_notifier_item(&self, service: String);
    fn register_status_notifier_host(&self, service: String);
    fn is_status_notifier_host_registered(&self) -> bool;
    fn registered_status_notifier_items(&self) -> Vec<String>;
    #[signal]
    fn status_notifier_item_registered(&self, service: &str);
    #[signal]
    fn status_notifier_item_unregistered(&self, service: &str);
}

3. 关键流程调用栈（伪码）

3.1 启动导出

流程 Service::start()
├── 连接会话总线
├── 申请 Watcher 名（allow-replacement）
│    └── 失败（已被他人持有且不让位）→ 返回 NameTaken
├── 挂载协议面（方法 + 两类信号）
├── 初始化空登记簿记
└── 返回 ServiceHandle

3.2 Item 报到

收到 RegisterStatusNotifierItem(唯一名+路径)
├── 在册 Item 表插入（已存在则幂等忽略）
└── 广播 StatusNotifierItemRegistered(唯一名+路径)

3.3 死亡清理

收到 NameOwnerChanged(唯一名, 旧属主 → "")
├── 在册 Item 表中移除该唯一名全部条目
│    └── 每条 → 广播 StatusNotifierItemUnregistered
└── 在册 Host 表中移除该唯一名（不广播）

3.4 让位

收到 NameLost（被外部 Watcher 顶替）
├── 清空全部簿记
├── 停止对外呈现（服务停止形态）
└── 记录已让位状态（不再受理登记）

3.5 停止

流程 ServiceHandle::stop()
├── 释放 Watcher 名（总线上名字消失，等同角色下线）
├── 清空登记簿记
└── 置已停止（幂等：重复调用直接返回）

boulanger 构建与开发

面向开发者的构建、测试与 CI 说明。项目描述见 README.html， 实现规格见 ARCHITECTURE.html 与 CODE.html。

构建依赖

项说明
Rust 工具链rustup / cargo
库依赖纯 Rust（zbus / thiserror / 标准库），无系统库依赖、零 GTK

本库必须独立编译测试，不要求 workspace 内其他工程存在（依赖约束见 ARCHITECTURE §6）。

构建与测试

cargo build
cargo test
cargo run -p boulanger   # 独立常驻形态（bin 目标），持有服务直至信号退出

CI 最低门禁

  • cargo build / cargo test 在无显示服务环境通过；
  • 仅需 DBus session bus（登记/广播/清理测试不依赖 Wayland/X11）；
  • 测试场景清单见 ARCHITECTURE.html §7。

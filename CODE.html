    ├── modules/
    │   ├── workspace.rs  # 反向映射 + 三态工作区条

    ├── style.rs          # CSS 变量加载与 RELOAD 热重载
    └── assets/
        └── bread.css     # 默认主题（变量定义）

3. 关键流程调用栈（伪码）

3.1 启动

启动
├── 连接 DBus 会话总线
├── 启动 boulanger 服务 → 服务句柄
├── 连接 breadpan → (Handle, 事件通道)
├── 连接 Hyprland IPC（只读监听）
├── 扫描已连接显示器
│    └── 对每台显示器
│         ├── 创建主窗口（layer-shell 锚定 Top|Left|Right）
│         └── 装配模块（workspace / window-info / tray / center）
├── 启动控制 Socket 监听（bread.sock）
├── 写 PID 文件
└── 进入事件循环

3.2 显示器插拔

on_hyprland_event(MonitorAdded)
└── 创建主窗口
     ├── layer-shell 锚定
     ├── 装配四个模块
     └── 登记映射表[显示器] = 窗口

on_hyprland_event(MonitorRemoved)
└── 销毁映射表[显示器] 指向的窗口
     └── 移除映射表条目

3.3 控制指令

on_control(指令)
├── Exit    → 销毁全部窗口 → 释放托盘句柄 → 停 boulanger 服务 → 退出进程
├── Toggle  → 切换全部窗口可见性
└── Reload  → 重读配置 → 重读 CSS 变量 → 应用到全部窗口

3.4 托盘右键（与 breadpan 协作）

用户右键托盘图标
├── 向 breadpan 发弹出前通知（AboutToShow）
├── menu() 现场拉取 → 菜单快照
├── GTK 渲染弹出菜单
├── 用户点击条目 → menu_activate 下发 → 受理结论
└── popup 打开期间收到 MenuChanged → 重取 menu() → 刷新菜单

3.5 通知到达

DBus Notify 调用
├── 组装通知记录（应用名/图标/摘要/正文/ID）
├── 缓存入通知列表
└── 刷新标题区计数/入口呈现

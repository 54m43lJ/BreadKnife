1. 文件树（规划）

breadknife/               # 项目群根（单一二进制 bread：daemon / 窗口 / 客户端 三角色）
├── breadpan/             # 成员项目（内部结构见其 CODE.html）
└── src/
    ├── main.rs           # 入口：子命令分发（daemon / open / close / …）
    ├── daemon/           # bread daemon（Model，无 GTK）
    │   ├── mod.rs        # 装配与事件循环；停机
    │   ├── hyprland.rs   # Hyprland IPC 只读监听：显示器 / 工作区 / 活动窗口
    │   ├── tray.rs       # breadpan 组装（Tray::start）+ 事件泵 + 交互执行 + 菜单读取
    │   ├── system.rs     # UPower / NetworkManager / MPRIS；pamixer / brightnessctl / ddcutil
    │   ├── notify.rs     # org.freedesktop.Notifications 实现（通知守护角色）
    │   ├── windows.rs    # 窗口进程生命周期（spawn / kill / 崩溃重启）；显示器 → 窗口映射
    │   └── ipc.rs        # Unix socket 服务端：请求应答 + 状态推送
    ├── window/           # 窗口进程（View，GTK4）
    │   ├── mod.rs        # 装配与 GTK 主循环；层壳窗口实例；数据分发（喂给对应模块）
    │   ├── ipc.rs        # IPC 客户端：快照 / 推送订阅、请求投递
    │   ├── style.rs      # 按 daemon 跟踪的路径加载 CSS；reload 重读
    │   └── modules/
    │       ├── workspace.rs    # 工作区条（渲染 + 手势捕获）
    │       ├── window_info.rs  # 活动窗口图标 / 标题 + 通知中心弹窗
    │       ├── tray.rs         # 托盘模块：图标渲染直出 + 手势捕获 + 菜单弹窗（自绘：懒加载 / 激活 / 刷新）
    │       └── center.rs       # 控制中心入口与弹出面板
    ├── shared/           # daemon / 窗口共用
    │   ├── protocol.rs   # IPC 消息类型（请求 / 应答 / 推送）
    │   └── model.rs      # 共享数据模型（窗口切片、状态增量）
    └── assets/
        └── bread.css     # 默认主题（变量定义）
  • 同一二进制承载三种角色：daemon、窗口（由 daemon spawn，bread window --monitor …）、客户端（指令转发）；
  • daemon/ 无 GTK 依赖；GTK 与 breadpan 渲染直出只在 window/；
  • 渲染归模块：窗口主进程只维护窗口实例与数据分发，一切渲染（含托盘菜单弹窗）由对应模块包干。

4. 关键流程调用栈（伪码）

4.1. 启动

4.1.1. daemon

启动（bread [daemon]）
├── notify::serve(conn)（通知守护注册）
├── EventBus::start()（.socket2.sock 只读监听）
├── Tray::start(config) → (handle, 事件通道)（登记中心就位 + 存量 Item 反向发现）
├── ipc::listen(path)（Unix socket）
├── hyprland::monitors()（显示器清单）
├── 对每台显示器
│    ├── spawn_window(mon)
│    └── push(window, snapshot)（接入后首连全量）
└── run()（事件循环）

4.1.2. 窗口进程

启动（bread window --monitor …）
├── ipc::connect(path)
├── style::load(css_path)（路径来自快照）
├── BarApp::create(app, monitor, ipc)（层壳窗口 + 模块装配）
│    ├── window.init_layer_shell()（锚定 Top|Left|Right）
│    ├── window.set_layer(Layer::Top)
│    ├── window.set_monitor(Some(monitor))
│    └── build_modules(window)
└── app.run()（GTK 主循环）

4.2. 窗口进程生命周期

4.2.1. 上线（显示器增加）

on_hyprland_event(MonitorAdded)
└── spawn_window(mon)
     ├── window_map.insert(mon, child)
     └── push(window, snapshot)（接入后首连全量）

4.2.2. 退出路径①：daemon 终止窗口进程

kill_window(mon)（exit / close / 显示器移除）
├── child.kill()（终止窗口进程）
└── window_map.remove(mon)

4.2.3. 退出路径②：窗口自主退出（daemon 死亡检测）

ipc::request(req) → Err（面向 daemon 的互动失败）
└── daemon_alive()（读 PID 文件 /run/user/$UID/bread.pid 探测 daemon 进程）
     ├── daemon 已退出 → app.quit()
     └── daemon 仍在 → 呈现错误、继续运行

4.2.4. 崩溃重启

on_window_exit(mon)（daemon 仍存活；等待子进程退出）
└── spawn_window(mon)（延时后重试；次数上限内，超限放弃并记录）

4.3. 控制指令

on_control(cmd)
├── Open / Close → spawn_window(mon) / kill_window(mon)
├── Reload → broadcast(Push::Reload)（窗口按跟踪路径重读 CSS）
├── Toggle → broadcast(Push::Visibility)
└── Exit → 对每台显示器 kill_window(mon) → handle.shutdown() → std::process::exit(0)

4.4. 托盘右键（窗口 ↔ daemon）

TrayWidget 手势：右键托盘图标
├── ipc::request(Request::TrayInteract { item, input: Right(x, y) })
│    └── daemon: right_click(item) → Outcome::Menu(snapshot)（阻塞在 daemon）
│         └── Outcome::Dispatched → ContextMenu fallback（Item 自绘，宿主不渲染）
├── TrayWidget::show_menu(snapshot)（GTK 弹窗渲染）
├── 条目点击 → ipc::request(Request::TrayMenuActivate { item, entry })
└── MenuChanged 推送 → ipc::request(Request::TrayMenuRead { item })（重取刷新）

4.5. 通知到达

DBus Notify 调用（daemon 通知守护）
├── NotificationRecord::from(args)
├── notifications.push(record)
└── broadcast(Push::Notification(record))（窗口侧：计数刷新 + 当前显示器弹窗）

4. 关键流程调用栈（伪码）

4.1. 启动

启动
├── dbus::connect()（通知守护注册）
├── Tray::start() → (handle, 事件通道)（登记中心就位 + 存量 Item 反向发现）
├── glib::spawn_future_local()（消费托盘事件流）
├── hyprland::listen()（.socket2.sock 只读监听）
├── 扫描显示器 → 对每台显示器
│    ├── spawn_window(mon)（layer-shell 锚定 Top|Left|Right）
│    └── build_modules(window)（workspace / window-info / tray / center）
├── control::listen()（bread.sock 行协议服务）
├── write_pid()
└── run()（事件循环）

4.2. 显示器插拔

on_hyprland_event(MonitorAdded)
└── spawn_window(mon)
     ├── window_create()（layer-shell 锚定）
     ├── build_modules(window)
     └── 显示器映射表[mon] = window

on_hyprland_event(MonitorRemoved)
└── destroy_window(mon)
     └── 移除显示器映射表条目

4.3. 控制指令

on_control(cmd)
├── Exit    → tray.shutdown() → destroy_windows() → 退出进程（释放 Watcher 名、停内部线程）
├── Toggle  → toggle_windows()（全部窗口可见性）
└── Reload  → reload()（重读配置与 CSS → 应用到全部窗口）

4.4. 托盘右键（与 breadpan 协作）

用户右键托盘图标
├── right_click(id) → Outcome::Menu(快照)（内含 AboutToShow）
│    └── Outcome::Dispatched → ContextMenu fallback（Item 自绘，宿主不渲染）
├── popup::show(快照)（GTK 渲染弹出）
├── 点击条目 → menu_activate(id, entry_id) → 受理结论
└── MenuChanged → menu() 重取 → 刷新弹出

4.5. 通知到达

DBus Notify 调用
├── on_notify()（组装通知记录：应用名/图标/摘要/正文/ID）
├── notification_list.push(record)
└── refresh_indicator()（标题区计数与入口呈现）

breadknife 实现骨架

1. 文件树

breadknife/               # 项目群根（单一二进制 bread：daemon / 窗口 / 客户端 三角色）
├── breadpan/             # 成员项目（内部结构见其 CODE.html）
└── src/
    ├── main.rs           # 入口：子命令分发（daemon / open / close / …）
    ├── daemon/           # bread daemon（Model，无 GTK）
    │   ├── mod.rs        # 装配与事件循环；停机
    │   ├── hyprland.rs   # Hyprland IPC 只读监听：显示器 / 工作区 / 活动窗口
    │   ├── tray.rs       # breadpan 组装（Tray::start）+ 事件泵 + 交互执行 + 菜单读取
    │   ├── system.rs     # UPower / NetworkManager / MPRIS；pamixer / brightnessctl / ddcutil
    │   ├── notify.rs     # org.freedesktop.Notifications 实现（通知守护角色）
    │   ├── windows.rs    # 窗口进程生命周期（spawn / kill / 崩溃重启）；显示器 → 窗口映射
    │   └── ipc.rs        # Unix socket 服务端：请求应答 + 状态推送
    ├── bar/              # bar 窗口进程（View，GTK4）
    │   ├── mod.rs        # 装配与 GTK 主循环；层壳窗口实例；数据分发（喂给对应模块）
    │   ├── ipc.rs        # IPC 客户端：快照 / 推送订阅、请求投递
    │   ├── style.rs      # 按 daemon 跟踪的路径加载 CSS；reload 重读
    │   └── modules/
    │       ├── workspace.rs    # 工作区条（渲染 + 手势捕获）
    │       ├── window_info.rs  # 活动窗口图标 / 标题 + 通知中心弹窗
    │       ├── popup.rs        # 弹窗会话：grab 弹窗统一托管（根窗口 / 上级弹窗定位 · 任务栏内捕获关闭 · Escape / toggle）
    │       ├── tray.rs         # 托盘模块：图标渲染直出 + 手势捕获 + 菜单弹窗（自绘：懒加载 / 激活 / 刷新）
    │       └── center.rs       # 控制中心入口与弹出面板
    ├── shared/           # daemon / 窗口共用
    │   ├── protocol.rs   # IPC 消息类型（请求 / 应答 / 推送）
    │   └── model.rs      # 共享数据模型（窗口切片、状态增量）
    ├── tests.rs          # 单元测试：协议回环 / 控制行解析 / 存活探测
    └── assets/
        └── bread.css     # 默认主题（变量定义）
  • 同一二进制承载三种角色：daemon、窗口（由 daemon spawn）、客户端（指令转发）；
  • 渲染归模块：窗口主进程只维护窗口实例与数据分发，一切渲染（含托盘菜单弹窗）由对应模块包干。

    fn on_tray(&mut self, ev: TrayEvent);
    fn reread_tray_view(&mut self, id: String);              // 独立线程现场重读
    fn degrade_tray(&mut self);
    fn on_window_request(&mut self, id: u64, request: Request, out: Sender<Frame>);

    fn on_control(&mut self, cmd: ControlCommand);

    fn snapshot_for(&self, monitor: &str) -> WindowSnapshot;

4. 关键流程调用栈（伪码）

4.1. 启动

4.1.1. daemon

启动（bread / bread daemon → __daemon）
├── protocol::pid_file() 校验（存活则拒绝）并写入自身 PID
├── hyprland::watch(tx)（socket2 只读监听线程）
├── tray::start(tx)（breadpan 组装；失败降级 None）
├── ipc::serve_control(control_path, tx)
├── ipc::serve_windows(window_path, tx)
├── system::start(tx)（UPower / NetworkManager / BlueZ / MPRIS）
├── Daemon::resync()
│    ├── hyprland::monitors() / workspaces() / workspace_rules()
│    ├── 首轮把显示器清单种入 desired（启动即逐屏 spawn）
│    ├── clear_urgent_on_active_transition()
│    ├── rebuild_workspace_slices()
│    ├── spawn_window(mon)（desired ∩ 现存显示器 − 在册）
│    └── push_workspace_slices()
└── Daemon::run_loop()
     ├── rx.recv_timeout(TICK) → Daemon::handle(ev)
     └── 超时档：pending_resync → Daemon::resync()

4.1.2. 窗口进程

启动（窗口进程，daemon spawn）
├── （未设 GSK_RENDERER 时）回退 cairo 渲染
├── bar::run(monitor, socket)
│    └── WindowApp::create(app, monitor, socket)
│         ├── IpcClient::connect(socket, monitor, ui_tx)（Hello 握手 + reader 线程）
│         ├── 层壳窗口：init_layer_shell / set_layer(Top) / 锚定 Left|Right|Top / namespace "bread" / auto_exclusive_zone_enable
│         ├── find_monitor(name) → set_monitor / set_default_size；connect_geometry_notify 跟踪分辨率
│         ├── PopupManager::install(window)
│         ├── WorkspaceWidget::new / WindowInfoWidget::new / TrayWidget::new / CenterWidget::new
│         ├── CenterBox 布局（workspace | info | tray + center）
│         ├── glib::timeout_add_local(UI_DRAIN)（排空 UiTask）
│         └── glib::timeout_add_seconds_local(2)（daemon_alive() 周期检查）
├── app.run_with_args(&[])
└── 首帧：Push::Snapshot → WindowApp::apply_snapshot（含 CSS 加载）

4.2. 窗口进程生命周期

4.2.1. 上线（显示器增加）

Hyprland monitoradded(v2) → Daemon::on_hyprland
├── desired.insert(monitor)
└── pending_resync = true
     └──（下一滴答）Daemon::resync()
          ├── hyprland::monitors() / workspaces() / workspace_rules()
          └── spawn_window(monitor) → windows::spawn(tx, monitor, window_path)
窗口 Hello → Daemon::on_window_request
└── ipc::hello_reply(out, id, snapshot_for(monitor))（先快照推送、后应答受理）

4.2.2. 退出路径①：daemon 终止窗口进程

Daemon::kill_window(monitor)（exit / close / 显示器移除）
├── WindowProc.killing = true
├── drop(WindowProc.out)（断开下行）
├── child.kill()
└── 独立线程 child.wait()（收割，避免僵尸残留）

4.2.3. 退出路径②：窗口自主退出（daemon 消失）

窗口：glib 定时（2s）protocol::daemon_alive()
├── false → app.quit()
└── true → 继续运行
互动失败：IpcClient::request → 重连一次重试
└── 仍失败 → Err（调用方记录；daemon 存亡由周期检查裁决）

4.2.4. 崩溃重启

windows::spawn 的探测线程：/proc/<pid>/stat 轮询（僵尸视为退出）
└── 退出并延时后 → DaemonEvent::ChildExited → Daemon::on_child_exited
     ├── killing = true → 返回（主动终止路径）
     ├── 不在 desired → 返回
     ├── 崩溃窗口期内计数 +1；超限 → desired.remove(monitor)
     └── spawn_window(monitor)（崩溃重启；间隔由探测线程延时上报形成）

4.3. 控制指令

ipc::serve_control → protocol::parse_control_line → DaemonEvent::Control → Daemon::on_control
├── Open { name, monitor } → open_windows()（desired 更新 + pending_resync）
├── Close { name, monitor } → desired.remove + kill_window()
├── OpenAll / CloseAll → 作用于全部显示器
├── Reload → broadcast(Push::Reload)（窗口按跟踪路径重读 CSS）
└── Exit → kill_window(全部) → TrayHandle::shutdown() → shutdown_files() → std::process::exit(0)

4.4. 托盘交互与菜单（窗口 ↔ daemon）

TrayWidget 手势（左 / 中 / 右 / 四向滚轮）
├── ipc::request(Request::TrayInteract { item, input })
│    └── daemon：tray::interact()（专用线程）

breadpan 架构规格

本文档面向消费方（依赖本库的应用与其开发者）：术语、架构图、对外接口契约与数据模型。 能力级边界以 README.html「本库不是什么」为权威； 内部结构与机制见 CODE.html。

1. 术语

术语含义
Watcher总线上的 org.freedesktop.StatusNotifierWatcher 服务，负责登记托盘项与宿主（官方定义 §4；由外部实现提供：环境自带，或由使用方自行组装）
Host托盘图标的展示方（即本库）。注册 org.freedesktop.StatusNotifierHost 并向 Watcher 登记（官方定义 §5）
Item一个托盘项，即某个应用在总线上导出的 org.freedesktop.StatusNotifierItem 对象（官方定义 §3）
MenuItem 通过 Menu 属性指向的 com.canonical.dbusmenu 对象（接口定义原文：reference/com.canonical.dbusmenu.xml）
会话总线DBus session bus，本库全部通信发生在此（D-Bus 规范）
zbus纯 Rust 的 DBus 实现，本库协议核心唯一的外部依赖
GTK 主线程GTK/GLib 主循环（MainContext）所在线程；一切 UI 操作与 gtk::bridge 交付的闭包都在此执行

2.2 事件投递链

每个事件的一条路；编号 = 下表环节:

 内部事件线程          库前端                       消费方
 ═══════════ ①  ════════════════ ②  ══════ ③  ═══════════
 事件出队 ──> on_event 回调 ──send──> Receiver ──bridge──> 闭包（GTK 主线程）
             按注册顺序串行      std::sync::mpsc  GLib 主循环搬运

三个环节可独立取舍：仅用 builder 时事件止于 ①（全部经回调投递）；Tray::connect 把 ① 接上 ②； ③ 仅由 GTK 整合层提供，非 GTK 消费方在任意线程 recv() ② 即可。

环节机制约束（机制未覆盖处）
① 回调
TrayBuilder::on_event		事件出队后由内部事件线程调用；注册多个时按注册顺序依次执行回调内阻塞会拖停内部线程，其后全部事件延迟；不得直接调用 GTK——需要主线程时沿链交给 ③
② 事件通道
Tray::connect · TrayHandle::subscribe		connect 以 ① 为底组装：回调把事件 send 进 std::sync::mpsc 通道并返回 Receiver；subscribe() 为同一内部流追加独立 Receiver；交付语义（顺序/去抖/背压）见 §3.2公开 API 全部为同步签名（能力级边界见 README.html）
③ GTK 桥接
gtk::bridge		向 GTK 主线程的 GLib 主循环注册内部转发，把 ② 的事件逐个搬到主线程调用消费方闭包闭包在主线程执行，阻塞即卡 UI

3. 接口

3.1 API 规范

公开面的唯一完整清单，签名即契约，注释只补充签名表达不了的语义。内部组装方式见 CODE.html。

// ── 配置 ──
pub struct TrayConfig {
    pub timeout_ms: u64,     // 服务发现/调用/心跳超时，默认 2000 ms
    pub debounce_ms: u64,    // 属性变更合并窗口，默认 50 ms
    pub menu_max_depth: u8,  // 菜单拉取最大深度，默认 8
}

// ── 入口 ──
impl Tray {
    /// 阻塞至完成 Host 登记（或超时）；通道首事件为快照，与后续事件原子衔接
    pub fn connect(config: TrayConfig) -> Result<(TrayHandle, Receiver<TrayEvent>), TrayError>;
    /// 底层原语（§2.2 投递链 ①）：事件全部经回调投递
    pub fn builder(config: TrayConfig) -> TrayBuilder;
}

impl TrayBuilder {
    /// 可多次调用；按注册顺序、在内部事件线程串行触发
    pub fn on_event(self, cb: impl Fn(&TrayEvent) + Send + 'static) -> Self;
    /// 组装并启动，语义同 connect
    pub fn spawn(self) -> Result<TrayHandle, TrayError>;
}

// ── Handle ──
pub struct TrayHandle;  // Clone + Send + Sync + 'static，全部方法线程安全

impl TrayHandle {
    pub fn items(&self) -> Vec<TrayItem>;
    pub fn item(&self, id: &TrayItemId) -> Option<TrayItem>;
    /// 零缓存：每次调用现场拉取；Item 无菜单或未就绪 → Err
    pub fn menu(&self, id: &TrayItemId) -> Result<MenuSnapshot, TrayError>;

    // ── 交互：同步返回受理结论；Item 侧异步结果经 InteractionResult 事件交付 ──
    pub fn activate(&self, id: &TrayItemId, x: i32, y: i32) -> Result<(), TrayError>;
    pub fn secondary_activate(&self, id: &TrayItemId, x: i32, y: i32) -> Result<(), TrayError>;
    pub fn scroll(&self, id: &TrayItemId, delta: i32, orient: Orientation) -> Result<(), TrayError>;
    pub fn menu_activate(&self, id: &TrayItemId, menu_item_id: i32) -> Result<(), TrayError>;
    /// AboutToShow；返回是否建议刷新
    pub fn menu_about_to_show(&self, id: &TrayItemId, menu_item_id: i32) -> Result<bool, TrayError>;

    /// 追加事件通道订阅者（§2.2 投递链 ②）
    pub fn subscribe(&self) -> Receiver<TrayEvent>;
    /// 优雅停机：注销 Host、停内部线程；幂等；最后一个实例 drop 时自动触发
    pub fn shutdown(&self);
}

pub enum Orientation { Horizontal, Vertical }  // ← SNI Scroll(STRING orientation)：horizontal / vertical

// ── GTK 整合层 ──
/// 主题命中 → 主题图标；未命中 → 位图纹理。须在 GTK 主线程调用
pub fn icon_paintable(icon: &IconSource) -> gdk::Paintable;
/// 事件通道 → GTK 主线程搬运（§2.2 投递链 ③）
pub fn bridge(rx: &Receiver<TrayEvent>, cb: impl FnMut(TrayEvent) + 'static);

// ── testing 特性：裸会话（仅需 DBus session bus）下的自足验证 ──
pub fn spawn_demo_item(config: TrayConfig) -> Result<DemoItem, TrayError>;
pub fn spawn_stub_watcher() -> Result<StubWatcher, TrayError>;

/// 可编程演示 Item：制造 Item 侧全部协议变化
impl DemoItem {
    pub fn set_status(&self, s: TrayStatus);        // Passive/Active/NeedsAttention 切换 → Changed
    pub fn set_icon_name(&self, name: &str);        // 主题图标 → Changed
    pub fn use_pixmap(&self, on: bool);             // 内嵌位图与主题图标间切换 → Changed
    pub fn set_tooltip(&self, t: Option<ToolTip>);  // 设置/清除 Tooltip → Changed
    pub fn menu_add(&self, label: &str) -> i32;     // 菜单增 → MenuChanged
    pub fn menu_toggle(&self, id: i32);             // 菜单改 → MenuChanged
    pub fn menu_remove(&self, id: i32);             // 菜单删 → MenuChanged
    pub fn toggle_menu(&self);                      // Menu 对象挂载/卸载 → MenuChanged
    pub fn set_unresponsive(&self, on: bool);       // 停止/恢复应答心跳 → Unresponsive
    pub fn remove(self);                            // 注销 Item 并退出 → Removed
}

补全（机制不覆盖的细则）：不安装任何全局状态，同进程可并行运行多个实例；本库不实现 Watcher、不拥有 UI、公开面零 async 等能力级边界以 README.html 为权威。

3.2 消息与错误

pub enum TrayEvent {
    /// 订阅起点：完整 Item 记录 + Watcher 存在性，与后续事件原子衔接
    Snapshot { items: Vec<TrayItem>, watcher_up: bool },
    Added(TrayItem),
    /// 服务名消失；同名重现（应用重启）视为新 Item（见 §3.3 TrayItemId）
    Removed(TrayItemId),
    /// 属性变更（去抖合并后的字段并集）
    Changed { id: TrayItemId, changed: Vec<ItemField>, item: TrayItem },
    /// dbusmenu 变更信号到达；不代为重拉，是否重取由消费方决定
    MenuChanged(TrayItemId),
    WatcherChanged(WatcherState),
    /// 心跳结论：无响应标记置位/解除（只标记，不移除）
    Unresponsive { id: TrayItemId, unresponsive: bool },
    /// 交互调用的异步回执
    InteractionResult { id: TrayItemId, op: InteractionOp, result: Result<(), String> },
    /// 内部过程叙述（重连、重扫描等）
    Narration(String),
    /// 终止宣告：最后一个事件，此后 Handle 方法一律返回 Stopped
    Fatal(String),
}

pub enum WatcherState { ExternalUp, ExternalDown }

/// ← 交互指令的官方方法：SNI §3.2 Activate / SecondaryActivate / Scroll；
///    dbusmenu Event("clicked") / AboutToShow
pub enum InteractionOp { Activate, SecondaryActivate, Scroll, MenuActivate, MenuAboutToShow }

/// 变更字段并集的成员：与 SNI 官方属性组一一对应；
/// 官方信号 New*（SNI §3.3）与 PropertiesChanged 均触发相应成员入集
pub enum ItemField {
    Status,        // ← Status（官方信号 NewStatus）
    Ident,         // ← Id
    Title,         // ← Title（官方信号 NewTitle）
    Icon,          // ← IconName + IconPixmap（官方信号 NewIcon）
    OverlayIcon,   // ← OverlayIconName + OverlayIconPixmap（官方信号 NewOverlayIcon）
    AttentionIcon, // ← AttentionIconName + AttentionIconPixmap（官方信号 NewAttentionIcon）
    Tooltip,       // ← ToolTip（官方信号 NewToolTip）
    WindowId,      // ← WindowId
    Category,      // ← Category
    IsMenuOnly,    // ← ItemIsMenu
    HasMenu,       // ← Menu
}

事件清单与建议动作

事件含义与触发建议动作
Snapshot启动完成即投递一次：全部 Item 记录 + Watcher 存在性初始化 UI
Added / Removed运行期 Item 出现 / 服务名消失（映射 Watcher 信号 StatusNotifierItemRegistered / StatusNotifierItemUnregistered，SNI §4.3）增删卡片
Changed属性变更（去抖合并，字段取并集）更新对应卡片
MenuChangeddbusmenu 三类变更信号到达（LayoutUpdated / ItemsPropertiesUpdated / AboutToShow，接口定义原文）决定何时重新 menu()
WatcherChangedExternalUp / ExternalDown（观察 IsStatusNotifierHostRegistered、StatusNotifierHostRegistered 信号与名字所有权变化；只观察，不补位）呈现登记中心状态
Unresponsive心跳结论：无响应置位/解除置灰 / 恢复（不移除）
InteractionResult交互调用的异步回执提示或日志
Narration内部过程性说明（重连、重扫描等）日志/调试
Fatal终止宣告，最后一个事件决定是否重建

投递语义

语义规定
快照启动完成即投递快照；此后仅增量事件，快照与事件流原子配对、无重叠无缺口
顺序同一 Item 的事件严格有序；全局不保证跨 Item 顺序
去抖PropertiesChanged 在合并窗口（默认 50 ms）内合并为一次 Changed，字段取并集
背压通道满：丢弃 + 告警计数，绝不阻塞内部线程（有损交付）
终止终止宣告是最后一个事件

错误

#[derive(Debug, thiserror::Error)]
pub enum TrayError {
    #[error("session bus connect failed: {0}")]
    Bus(String),
    #[error("operation timed out after {ms} ms")]
    Timeout { ms: u64 },
    #[error("item {0} not found")]
    ItemNotFound(String),
    #[error("dbus call failed: {0}")]
    Protocol(String),
    #[error("tray runtime stopped")]
    Stopped,
}
错误含义与场景建议动作
Bus会话总线连接失败检查 session bus 环境后重试 connect
Timeout服务发现 / 调用 / 心跳超时（timeout_ms）重试，或放宽 TrayConfig::timeout_ms
ItemNotFoundItem 不在册 / 无菜单或未就绪以最新快照或 Changed 事件校准后再操作
Protocol协议类失败（属性缺失、类型不符等）跟踪面已字段级降级（见 §3.3）；menu() 现场读取与交互受理阶段返回本错误，可重试或跳过该 Item
Stopped终止宣告之后的一切调用库已停机，按需重建实例

容错总则：单个 Item 的死亡不影响其他 Item 的跟踪；协议类错误绝不 panic；总线断开 → Fatal → Stopped，重建由消费方决定。

TrayItemId / TrayItem 字段定义

字段含义规范依据
id.service唯一键：Item 注册到 Watcher 的服务名。官方命名 org.freedesktop.StatusNotifierItem-PID-ID（PID=进程号，ID=同进程实例序号）；对象路径不参与标识：服务名消失 → Removed，同名重现（应用重启）→ 视为新 Item（Added）；pid 仅能从服务名 PID 段解析SNI §3；总线名构成见 D-Bus 规范 · Bus Names
categoryApplicationStatus / Communications / SystemServices / HardwareSNI §3.1 Category
statusPassive 可隐藏 / Active 应展示 / NeedsAttention 应强调SNI §3.1 Status
ident应用内唯一、跨会话一致（如应用名）；识别用，不用于展示SNI §3.1 Id
title面向用户展示名，可比 ident 更具描述性SNI §3.1 Title
is_menu_only为真时优先展示菜单而非 ActivateSNI §3.1 ItemIsMenu
window_id宿主窗口 id；不关心时为 0SNI §3.1 WindowId（UINT32）
icon / overlay_icon / attention_icon图标来源，二选一规则见 IconSource 字段表SNI §3.1 IconName + IconPixmap / OverlayIcon* / AttentionIcon*
tooltip悬停提示；描述可含标记子集，原样透传SNI §3.1 ToolTip · §7 标记子集
has_menuMenu 属性非空；菜单对象路径由内部保存供 menu() 使用SNI §3.1 Menu（OBJECT PATH）

历史实现普遍以 org.kde.* 前缀提供同一接口（如 nm-applet）：监听与调用对 org.freedesktop.*（原文拼写）与 org.kde.* 两套前缀等价处理，表述以原文为准。

ToolTip / IconSource / Pixmap 字段定义

字段含义规范依据
ToolTip.icon / title / description官方四元组 (STRING, a(iiay), STRING, STRING) 的映射：图标来源 + 标题 + 描述SNI §3.1 ToolTip
IconSource::NameFreedesktop 图标名；渲染直出时按主题规范查主题Icon Naming Spec · Icon Theme Spec

MenuSnapshot / MenuItem 字段定义

字段含义规范依据
MenuSnapshot.revision布局版本号，与 dbusmenu LayoutUpdated.revision 对应dbusmenu · GetLayout
MenuSnapshot.root递归全量布局（recursionDepth = -1），深度截断于 menu_max_depthdbusmenu · GetLayout（recursionDepth：-1 全部/0 不递归/n 层）

kindstandard / separator / submenu（type + children-display="submenu"）dbusmenu · type / children-display
label已解析助记符：__ 显示为 _，第一个剩余 _ 后字符为访问键dbusmenu · label
raw_labellabel 原始值（逃生门）dbusmenu · label
enabled / visible可用 / 可见；官方缺省 true——仅非默认值的属性才会上报，组装时按默认值补全dbusmenu · enabled / visible
toggledtoggle-type ∈ {checkmark, radio} 时按 toggle-state：1→Some(true)，0→Some(false)，其余/缺省 -1→None；radio 组互斥由 Item 侧维护dbusmenu · toggle-type / toggle-state

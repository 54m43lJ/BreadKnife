breadpan 构建与开发

面向开发者的构建、测试与 CI 说明。项目描述见 README.html， 实现规格见 ARCHITECTURE.html 与 CODE.html。

构建依赖

项说明
Rust 工具链rustup / cargo
协议核心纯 Rust（zbus），无系统库依赖
GTK 整合层gtk4 / glib 开发包（Arch: pacman -S gtk4）

本库必须独立编译测试，不要求 workspace 内其他工程存在（独立性硬约束见 ARCHITECTURE §11）。

构建与测试

cargo build
cargo test
cargo test --features testing   # 含测试替身（演示 Item / Watcher 替身）

CI 最低门禁

  • cargo build / cargo test 在无显示服务环境通过；
  • 仅需 DBus session bus（集成测试不依赖 Wayland/X11）；
  • 测试场景清单见 ARCHITECTURE.html §12。

breadpan 构建与开发

面向开发者的构建、测试与 CI 说明。项目描述见 README.html， 实现规格见 ARCHITECTURE.html 与 CODE.html。

构建依赖

项说明
Rust 工具链rustup / cargo
协议核心依赖白名单zbus（启用 tokio 特性）、tokio（sync + rt，仅库内部运行时）、zvariant / serde（属性 → 原生结构反序列化）、thiserror、标准库——事件通道为 tokio mpsc
GTK 整合层gtk4 / glib 开发包（Arch: pacman -S gtk4）
测试环境仅需 DBus session bus；无需显示服务（不依赖 Wayland/X11）

本库必须独立编译测试，不要求 workspace 内其他工程存在。

构建与测试

cargo build
cargo test
cargo run --example minimal   # 运行示例（examples/ 为唯一示例目录，见 README「实例代码」）

breadpan 构建与开发

面向开发者的构建、测试与 CI 说明。项目描述见 README.html， 实现规格见 ARCHITECTURE.html 与 CODE.html。

构建依赖

项说明
Rust 工具链rustup / cargo
协议核心依赖白名单zbus、thiserror、标准库；事件通道用 std::sync::mpsc——纯 Rust，无系统库依赖
GTK 整合层gtk4 / glib 开发包（Arch: pacman -S gtk4）
测试环境仅需 DBus session bus；无需显示服务（不依赖 Wayland/X11），集成测试经 testing 替身在裸会话完成

本库必须独立编译测试，不要求 workspace 内其他工程存在。

构建与测试

cargo build
cargo test
cargo test --features testing   # 含测试替身（演示 Item / Watcher 替身）

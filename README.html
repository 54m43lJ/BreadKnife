BreadKnife

专为 Hyprland 设计的 Wayland 任务栏：屏幕顶部一条常驻栏，集工作区、窗口信息、系统托盘与控制中心于一体，开箱即用。
二进制名 bread；本仓库同时是项目群根，内嵌 breadpan 成员项目。

WHAT & WHY

要解决的问题

在 Hyprland（Wayland）会话中呈现工作区、窗口信息、系统托盘与系统状态，需要自行拼装组件并处理 合成器 IPC、DBus 协议、托盘协议栈等细节——缺乏一个开箱即用、体验完整的整体方案。 breadknife 不做通用框架，而是以精品应用的形态直接回答这个问题。

成功长什么样

  • 多显示器：每屏一条任务栏，随显示器插拔自动出现/消失；
  • 即点即用：工作区点击即达；托盘图标左键/右键即刻生效；
  • 一目了然：音量、亮度、媒体、时钟、网络、电池常驻可见，通知集中缓存查看；
  • 零配置可用：默认主题开箱即用；想换外观时改一份 CSS 变量文件，RELOAD 改色即见；
  • 边界清晰：不支持 X11 或其它合成器——精品应用而非通用框架。

使用与原型

界面交互

功能域行为
工作区切换每屏显示本屏的工作区条；点击切换；滚轮切换：上＝左侧工作区、下＝右侧工作区，滚轮左右自然对应
窗口信息显示当前活动窗口的应用图标与标题；标题过长自动截断，悬停看全文
通知弹窗通知到达时在任务栏正下方居中弹出（仅当前显示器）：标题居中、右上角带关闭按钮；左键触发通知动作，无动作时回退为切换到来源程序所在工作区并聚焦其窗口；中键关闭该条，右键关闭全部；普通与低优先级 30 秒后自动消失，紧急通知常驻至手动关闭，用户空闲期间不移除
通知中心点击标题区域弹出通知列表；应用发出的桌面通知在此缓存与查看
系统托盘自动发现应用的托盘图标并显示；支持左键/中键/滚轮（含水平）/右键交互；悬停显示提示；失联图标置灰、应用退出后移除
控制中心常驻入口：电池（无电池设备自动隐藏）、网络状态、实时时钟；弹出面板：媒体控制、音量/亮度滑块、网络/蓝牙状态、日历

工作区按钮按「要素 × 条件」矩阵决定（条件优先级从高到低＝紧急 → 活跃 → 有/无窗口，高者覆盖低者）：

有窗口无窗口活跃紧急
长方形显示无无显示
圆点无显示显示无
长方形颜色背景色无无警告色
圆点颜色无背景色前景色背景色
  • 色彩角色均取色板（不改定义）：背景色＝surface、前景色＝fg、警告色＝gold；
  • 工作区条＝本屏现存工作区 ∪ 绑定到本屏的静态 workspace 规则（hyprctl -j workspacerules，两者按名去重 + id 排序）——有规则而当前无窗口的即"非活跃工作区"，随规则常驻显示；
  • 活跃且无窗口：叠加圆点与基底圆点等大重叠，视觉为单个前景色小圆点；
  • 紧急为持久状态：仅"切换到该工作区"或"该工作区活跃时点击"清除；活跃工作区的窗口请求关注时同样显示。
  • 托盘菜单为经典嵌套式交互（对齐 Windows / KDE / macOS）：同级条目悬停驻留约 150ms 即展开其子菜单（鼠标无需点击）；悬停其它条目收起相关子层、回到父条目或菜单空白保留、指针离开菜单不关；点击菜单外关闭（该次点击被吞），任务栏内点击直达（无需先关闭）；Escape 关闭；
  • 菜单外观（macOS 式）：无气泡尾与描边环、平铺面板贴边——根菜单贴任务栏下缘，子菜单与父面板边缘相接、顶边与所在条目对齐；
  • 菜单跟踪（macOS 菜单栏式）：已有弹窗显示时，悬停托盘图标约 150ms 驻留即直接切换到该图标的菜单（弹窗抓取期间任务栏收不到悬停事件，故由合成器指针轮询驱动）；掠过不触发，无弹窗时悬停不打开任何菜单。

控制指令

daemon 常驻运行后，通过 bread 客户端下达指令（底层为 Unix Socket 行协议，契约见 ARCHITECTURE.html §4.2）： 

bread open-all                    # 打开全部窗口
bread close-all                   # 关闭全部窗口
bread open <name> [-m <monitor>]   # 打开指定窗口（可限定显示器）
bread close <name> [-m <monitor>]  # 关闭指定窗口
bread reload                      # 热重载配置与 CSS 样式（改完即生效，无需重启）
bread exit                        # 退出 daemon

个性化

一份 CSS 变量文件定义整套外观（底板色、文字色、强调色、语义色、边框），组件样式全部基于这些变量； 修改变量文件后执行 bread reload 即可"改色即见"（CSS 文件路径由 daemon 跟踪）。变量清单见 ARCHITECTURE.html §3.9。

运行管理

daemon 与窗口为独立进程：bread 前台启动 daemon，bread daemon 自动后台化； daemon PID 位于 /run/user/$UID/bread.pid。每个显示器一个窗口进程，由 daemon 随显示器插拔自动创建与回收。

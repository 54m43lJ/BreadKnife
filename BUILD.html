breadknife 构建与开发

面向开发者的构建与本地运行说明。项目描述见 README.html， 实现规格见 ARCHITECTURE.html 与 CODE.html。

系统依赖

Arch Linux

sudo pacman -S --needed rustup gtk4 gtk4-layer-shell
rustup default stable

其他发行版

安装 Rust 工具链与 GTK4、gtk4-layer-shell 开发包即可。

构建

cargo build            # 开发构建
cargo build --release  # 发布构建 -> target/release/bread
cargo test

本地运行

  • 前提：Hyprland（Wayland）会话 + DBus session bus；
  • ./target/release/bread 启动守护进程；
  • 运行状态探测与退出指令见 README.html §使用与原型。

发布与版本策略

  • 暂不发布 crates.io：项目群以单一仓库内部依赖使用；
  • 版本策略照常遵循 SemVer；各库自身的版本与稳定性条款见各自 ARCHITECTURE.html 的版本章节。

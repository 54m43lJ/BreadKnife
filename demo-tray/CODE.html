demo-tray 实现骨架

状态：草稿（待评审定稿）。本档记录比架构更底层的实现细节：文件树、类型与方法签名（Rust 语法）、 关键流程调用栈（中性伪码，不采用语言风格、不死抠方法内部逻辑）。 上层语义见 ARCHITECTURE.html。

1. 文件树（规划）

src/
├── main.rs          # 入口：组装 → 启动 GTK 主循环
├── app.rs           # 窗口装配：卡片流 + 事件日志 + 测试台
├── cards.rs         # 卡片流：Item → 卡片视图，事件驱动更新
├── log.rs           # 事件日志：TrayEvent → 单行文本（带时间戳）
└── bench.rs         # 测试台：演示 Item + 总线名替身（均本工具内部实现，导出 SNI / dbusmenu 对象）

2. 类型与方法签名

pub struct App {
    tray: breadpan::TrayHandle,
    rx: Receiver<breadpan::TrayEvent>,
    stub: Option<bench::StubWatcher>,           // 总线名替身（占名 / 申请同名；本工具内部实现）
    demo: Option<bench::DemoItem>,              // 演示 Item 句柄（本工具内部实现）
    cards: CardsView,
    log: EventLog,
}

pub struct CardsView { by_item: HashMap<TrayItemId, CardRow> }

pub struct CardRow {
    icon: gdk::Paintable,   // 经 breadpan 渲染直出
    status: TrayStatus,
    title: String,
    greyed: bool,           // 无响应置灰（只标记不移除）
}

pub struct EventLog { /* 只追加文本视图 */ }

impl App {
    pub fn run() -> Result<(), Error>;   // 组装 → 主循环
    fn on_tray_event(&self, ev: breadpan::TrayEvent);
    fn on_bench_command(&self, cmd: BenchCommand);
}

pub enum BenchCommand {
    Status(TrayStatus),
    Icon(String),
    Pixmap(bool),
    Tooltip(Option<String>),
    MenuAdd(String),
    MenuToggle(i32),
    MenuRemove(i32),
    ToggleMenu,
    Unresponsive(bool),
    RemoveItem,
    WatcherClaim,
}

3. 关键流程调用栈（伪码）

3.1. 启动组装

流程 App::run()
├── Tray::start（本工具替身就绪）→ (Handle, 通道)
│    （登记中心就位 + 存量 Item 反向发现）
├── 创建窗口：卡片流（上）+ 事件日志（下）+ 测试台控件
├── glib::spawn_future_local 异步消费事件流（GTK 主线程）
├── 注册演示 Item（测试台初始动作）
└── 进入 GTK 主循环

3.2. 事件消费

on_tray_event(ev)
├── 日志追加一行（时间戳 + 事件类型 + 摘要）
└── 按事件类型更新卡片流
     ├── Snapshot → 重建全部卡片
     ├── Added → item(id) 现场读取 → 新建卡片（icon_paintable 渲染直出）
     ├── Changed → item(id) 重读 → 更新卡片字段
     ├── Removed → 删除卡片
     ├── 周期重读 alive=false → 置灰；alive=true → 恢复
     └── 其余（MenuChanged / Displaced / 回执 / 叙述 / 终止）→ 仅日志呈现

3.3. 右键菜单

用户右键卡片
├── right_click() → Outcome::Menu(快照)（Menu 流程内含 AboutToShow）
├── 按 kind 渲染 GTK 弹出菜单（Separator/子菜单/勾选态）
├── 条目点击 → menu_activate
├── popup 打开期间收到 MenuChanged
│    └── 重取 menu() → 替换菜单内容（保持弹窗）
└── 全程日志可见

3.4. 测试台指令

on_bench_command(cmd)
├── Item 侧指令 → 调 DemoItem 对应方法（status/icon/pixmap/tooltip/menu/…）
├── Unresponsive(on) → DemoItem 停止/恢复应答（制造 alive=false / true 变化）
├── WatcherClaim → spawn 替身申请同名 → 日志呈现申请结论
│    （Tray 持有期被拒 / Tray 停机后替身持有成功）；stub = Some(句柄)
└── RemoveItem → DemoItem 注销；demo = None

3.5. 关闭清理

窗口关闭
├── drop 演示 Item（自动注销）
├── TrayHandle::shutdown（释放 Watcher 名、停内部线程）
└── drop 总线名替身 → 退出

demo-tray 构建与开发

面向开发者的构建与运行说明。项目描述见 README.html， 实现规格见 ARCHITECTURE.html 与 CODE.html。

构建依赖

项说明
Rust 工具链rustup / cargo
GTKgtk4 开发包（Arch: pacman -S gtk4）
workspace 依赖breadpan（本仓库成员）

构建与运行

cargo build
cargo run -p demo-tray   # 一条命令在本地会话中启动

运行前提

  • DBus session bus（必需）；
  • Wayland 会话 + GTK（窗口呈现）；
  • 纯 Hyprland（无任何托盘环境）即可完整运行——托盘协议栈随库内置（Tray::start 即含登记中心），演示 Item 由本工具自备；
  • 验收操作与预期观察的对照表见 ARCHITECTURE.html §7。

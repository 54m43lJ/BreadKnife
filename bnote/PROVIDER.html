bnote 依赖契约

bnote 绑定的底层是 DBus 会话总线上的 org.freedesktop.Notifications 服务：连接由本库内部建立并持有，装配时注册并实现该服务；客户端的方法调用经总线进入，三个信号经总线回发。协议完整定义以 reference/ 为唯一权威，本文只登记本库实现的面；宿主侧契约见 USER.html。

1. 术语

术语定义
DBus 会话总线底层消息总线，本库与其客户端之间的方法调用与信号中介
服务名org.freedesktop.Notifications；本库装配时在总线上注册占用
客户端经总线调用方法、接收信号的发送方（notify-send、应用等）
hintsNotify 携带的附加键值对（紧急度、图像数据等），本库负责解析归一

4.2. 信号回发

NotificationClosed(id: u32, reason: u32)
ActionInvoked(id: u32, action_key: String)
ActivationToken(id: u32, token: String)
信号触发
NotificationClosed通知被关闭（过期 / 用户 / 客户端请求），原因码归一见 §4.3
ActionInvoked宿主转达用户对动作的点击
ActivationToken宿主转达启动激活令牌

4.3. 参数归一与信号编码

入站

协议元素归一目标规则
replaces_idNotice.id非 0 沿用；0 由本库新分配；交付宿主的 id 恒非 0（规范 §Notify）
app_nameNotice.app_name原样
summaryNotice.summary原样
bodyNotice.body原样
actions 参数Notice.actions按（key, label）成对解析；奇数个 → Error::InvalidArgs
hint urgencyNotice.urgencybyte 0/1/2 → Low / Normal / Critical；缺失、未知值或类型不符 → Normal
app_icon 与 hints image-data / image-path / icon_dataNotice.icon按规范优先级取一个：image-data > image-path > app_icon > icon_data；app_icon / image-path 非空 → NoticeIcon::Name（主题名或 file:// URI）；image-data / icon_data 为 8-bit、3/4 通道 → NoticeIcon::Pixels（RGB/RGBA，按 rowstride 压紧）；全空 → NoticeIcon::None
expire_timeout 参数Notice.expire_timeout_ms-1（及其它负值）→ None（按宿主默认）；0 → Some(0)（常驻）；正数 → Some(ms)（规范 §Notify）
  • 未知 hint 键忽略；不支持的 image-data / icon_data 不报错，按上述优先级回退；image-data 的 bits_per_sample 必须为 8，has_alpha 为真时 channels 必须为 4，否则忽略该 hint。格式与优先级见 规范 §5，hints 表见 规范 §8。

出站

内部数据协议元素规则
CloseReason::ExpiredNotificationClosed.reason1
CloseReason::DismissedNotificationClosed.reason2
CloseReason::CloseRequestNotificationClosed.reason3；客户端 CloseNotification 时由本库自动发出
Notice.idNotificationClosed.id / ActionInvoked.id / ActivationToken.id原样
Action.keyActionInvoked.action_key原样
activation_token 的 token 参数ActivationToken.token原样
  • 原因码 4（undefined/reserved）不由本库发出；规范定义见 §9.2.1。
  • 归一目标的数据对象定义见 USER §4.3。

4.4. 错误应答

org.freedesktop.DBus.Error.InvalidArgs(message)
org.freedesktop.DBus.Error.Failed(message)
错误含义 / 客户端动作
InvalidArgsNotify / CloseNotification 参数不合法（actions 非成对、id 非法等）；修正后重试
Failed服务端内部失败（归一、序列化、事件投递）；记录并重试或降级
  • 未知 hints、未知 urgency 值或不支持的 image-data 不返回错误：前者忽略，urgency 回退 Normal，图像 hint 按 §4.3 回退。
  • 错误名沿用 D-Bus 标准错误；规范未定义通知专用错误，权威定义见 D-Bus 规范 · Errors。

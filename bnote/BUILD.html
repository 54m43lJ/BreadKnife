bnote 构建与开发

面向开发者的准备、构建、示例与测试说明。项目描述见 ABOUT.html， 使用契约见 USER.html，外部协议见 PROVIDER.html， 实现规格见 CORE.html。

1. 开发者准备

项说明
Rust 工具链rustup / cargo（edition 2024）
运行时依赖zbus（tokio 特性）、tokio——均由库内部持有，宿主不装配
开发依赖futures-util（协议集成测试消费信号流）
测试环境DBus session bus；无需显示服务
  • 本库为独立 crate（仓库内路径 bnote/），须独立编译测试，不要求仓库内其他工程存在；下述命令均在 bnote/ 目录内执行。

2. 开发命令

cargo build
cargo build --release
cargo test                                            # 协议集成测试
dbus-run-session -- cargo test                        # 隔离 session bus 全量运行（推荐）
cargo run --example server                            # 交互式测试服务器

3. 安装指南

3.1. Linux

路径依赖

作为路径依赖加入宿主清单：

[dependencies]
bnote = { path = "../bnote" }   # 或发布后的版本号

运行前提：DBus session bus 可用，且 org.freedesktop.Notifications 未被其它通知守护持有；名字被占用时 Session::start 返回 NameTaken，由宿主决定重试或降级。

4. 补充说明

  • 协议集成测试在隔离 session bus 上运行，覆盖方法应答、事件交付与信号回发；
  • examples/server.rs 经 stdin 驱动宿主 API，用于手工验证通知、关闭、动作与令牌回发；
  • 协议原文清理版见 reference/，以其中的分章文件为准。

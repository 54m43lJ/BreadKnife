bnote 实现骨架

1. 文件树

bnote/
├── reference/          # 官方规范清理版（协议唯一权威文本）
├── src/
│   ├── lib.rs        # 门面：会话装配、错误类型、再导出
│   ├── server.rs     # org.freedesktop.Notifications 服务端方法应答
│   ├── signal.rs     # NotificationClosed / ActionInvoked / ActivationToken 发射
│   ├── hints.rs      # hints 解析与归一（urgency / actions / 图标 / 超时）
│   └── types.rs      # Notice / NoticeEvent / 能力等共享类型
└── examples/
    └── server.rs     # 交互式通知服务器测试器（用法见 README「原型 / 参考资料」）
  • 本库无 GTK、无业务状态：只做协议应答、信号发射与归一化；展示与生命周期决策全部归宿主。

2. 通用约定

  • 规范条文引用一律指向 reference/notification-spec.clean.html 的对应小节，不在注释里复述协议原文。

4. 关键流程调用栈（伪码）

4.1. 通知到达

DBus Notify 调用 → Server::notify()
├── hints::parse()（urgency / actions / 图标 / 超时归一）
├── id 分配（replaces_id 非 0 沿用，否则新分配）
├── Session 转 NoticeEvent::Notify → tx（宿主）
└── 应答新 id

4.2. 关闭与回发

两条入口，同一出口：
├── 客户端 CloseNotification(id) → Server::close_notification()
└── 宿主决定关闭（超时 / 用户交互）→ signal::emit_closed()
出口：signal::emit_closed(id, reason)（NotificationClosed 信号，规范 §9.2.1）

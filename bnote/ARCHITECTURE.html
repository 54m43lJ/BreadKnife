bnote 架构

1. 术语

术语定义
宿主装配本库、承担通知守护角色的进程，即 bread daemon 的消息中心模块
通知（Notification）客户端经 Notify 方法提交的一条消息，归一后为 Notice（见 §4.3）
紧急度（Urgency）hint urgency 的归一值：Low / Normal / Critical；决定宿主的超时策略
动作（Action）通知携带的可点击项：键（key）＋标签（label）；客户端经 ActionInvoked 得知用户点击
能力（Capability）守护声明支持的特性串（GetCapabilities 应答），如 actions、body-markup
关闭原因（Reason）NotificationClosed 信号携带的数值码：过期 / 被用户关闭 / 被 CloseNotification 调用关闭

4.3. 数据模型与转换

pub struct Notice {             // 待实现，可以根据实际情况调整
    pub id: u32,
    pub app_name: String,
    pub icon: NoticeIcon,
    pub summary: String,
    pub body: String,
    pub actions: Vec<Action>,
    pub urgency: Urgency,
    pub expire_timeout_ms: Option<u32>,
}

pub enum Urgency { Low, Normal, Critical }
pub struct Action { pub key: String, pub label: String }
pub enum NoticeIcon { None, Name(String), Pixels { width: i32, height: i32, rgba: Vec<u8> } }
字段定义来源（规范转换）
id通知唯一标识；0 表示由本库分配replaces_id 非 0 时沿用，否则新分配（规范 §Notify）
app_name / summary / body应用名 / 标题 / 正文Notify 同名参数原样
icon图标三态：无 / 主题名 / 位图app_icon 参数与 hint image-data 系列合并归一
actions键值对列表，键用于 ActionInvoked 回发actions 参数按（key, label）成对解析
urgency紧急度hint urgency（byte 0/1/2）；缺省 Normal
expire_timeout_ms请求的超时；None＝常驻（-1），0＝按宿主默认expire_timeout 参数归一

1. WHAT & WHY

IDEAL

bread 的通知守护要正确实现 org.freedesktop.Notifications 的全部协议行为——方法应答、信号回发、hints 归一、能力协商。这些细节繁杂且与业务无关，不应散落在 daemon 业务代码里。

GOAL

一个独立封装该协议的库：宿主（bread daemon 的消息中心模块）只面向结构化的通知事件与动作回发 API，不见任何 DBus 协议细节；协议行为与官方规范逐条对应，可独立测试。

2. 用户交互

  • 本库无图形界面；「用户」即宿主进程。
  • 宿主装配会话后订阅通知事件流；对外回发（关闭、动作、激活令牌）通过显式 API 调用，见 ARCHITECTURE.html。

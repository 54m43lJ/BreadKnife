breadknife 依赖契约

本文档定义 bread 消费的外部协议与系统服务：只记录实际消费的子集，完整权威定义见 reference/ 与各厂商文档。

1. 术语

术语定义
Hyprland IPCHyprland 合成器在 $XDG_RUNTIME_DIR/hypr/$HYPRLAND_INSTANCE_SIGNATURE/ 下提供的 Unix Socket 事件流；本项目的显示器 / 工作区 / 活动窗口 / 紧急状态 / 最小化集合来源
workspace 规则Hyprland 配置中的静态工作区绑定，决定哪些工作区常驻显示在某显示器
最小化工作区Hyprland 特殊工作区 special:minimized；bread 以其中的客户端作为最小化集合
调节后端音量与亮度的外部命令行工具；缺席时对应功能降级

2. 通用约定

  • 只读监听：Hyprland IPC 只订阅事件，不向该 Socket 回复；查询类数据经 hyprctl 获取。
  • 缺失降级：DBus 服务或外部工具缺席时，对应入口隐藏或操作项灰置，不阻断其余功能。
  • 错误隔离：单个服务 / 工具失败只影响该能力域，不终止 bread。

4.1. Hyprland IPC

事件流路径：$XDG_RUNTIME_DIR/hypr/$HYPRLAND_INSTANCE_SIGNATURE/.socket2.sock；契约：只订阅不回复。

事件契约
monitoradded / monitorremoved创建 / 销毁对应显示器的任务栏
workspace>>X更新工作区映射并推送工作区切片
activewindow更新并推送活动窗口
urgent>>X窗口请求关注 → 所在工作区紧急位置位（清除语义见 ABOUT.html「界面交互」）
movewindowv2窗口移入 / 移出最小化工作区 → 重同步最小化托盘
openwindow / closewindow窗口打开 / 关闭 → 重同步最小化托盘
windowtitlev2更新最小化托盘条目标题
minimized>>ADDR,0/1外部 taskbar 请求最小化 / 恢复 → 将窗口移入 / 移出最小化工作区
configreloaded全量重同步：重扫显示器清单、重建映射、重读最小化集合并对齐任务栏
接口消费内容
hyprctl clients -jaddress / class / title / workspace.name / monitor；过滤 special:minimized 并确定归属显示器
hyprctl monitors -jfocused（当前显示器判定）、当前活动工作区（恢复目标）、宽度（托盘宽度上限）
hl.dsp.window.move({ workspace, window, follow = false })移入最小化工作区或恢复到活动工作区
hl.dsp.focus({ window })恢复后聚焦窗口
hl.dsp.window.close({ window })关闭最小化窗口
  • 查询类数据（显示器、工作区、客户端、workspace 规则）经 hyprctl -j 获取；字段口径以 reference/hyprland-ipc.html、hyprctl、dispatcher 为准。
  • 工作区切换与最小化窗口操作经 dispatcher 执行；窗口选择器统一用 address:，Lua dispatch 失败时回退经典语法，见 CORE §4.3。
  • minimized 事件仅由外部 taskbar 通过 wlr-foreign-toplevel 请求触发；普通 CSD 最小化不保证产生。bread 以 special:minimized 工作区为准，事件只作为辅助触发。
  • 通知弹窗的当前显示器使用 hyprctl -j monitors 的 focused 字段；不启用 .socket.sock 查询，保持 socket2 只读与单一查询路径。

4.2. 系统 DBus 服务

服务消费内容缺席行为
UPower（system bus）电池电量与充电状态电池入口隐藏
NetworkManager（system bus）网络连接状态网络入口隐藏
BlueZ（system bus）蓝牙开关与连接数蓝牙项隐藏或灰置
MPRIS（session bus）媒体播放状态与控制媒体控制灰置
  • 仅消费上述状态与操作子集；完整接口定义见 UPower、 NetworkManager、 BlueZ 与 MPRIS。
